

**Smart Stream** est une application web responsive de consultation de chaînes TV, développée avec HTML5, Tailwind CSS et JavaScript Vanilla ES6+.

## Objectif
Permettre aux utilisateurs de consulter, rechercher, filtrer et sélectionner des chaînes TV à travers une interface simple et interactive.

##  Technologies
- HTML5
- Tailwind CSS
- JavaScript Vanilla ES6+
- Fetch API & MockAPI
- Git & GitHub
- Jira

## Fonctionnalités
- Affichage dynamique des chaînes TV.
- Prévisualisation interactive après sélection.
- Recherche instantanée par nom ou numéro.
- Filtrage des chaînes par pays.
- Interface responsive Mobile-First.

##  Concepts étudiés
- Variables, constantes, tableaux et objets.
- Fonctions et fonctions fléchées.
- Modules ES6 (`import` / `export`).
- Méthodes `forEach()`, `map()` et `filter()`.
- Manipulation du DOM et gestion des événements.
- Recherche avec `includes()` et `toLowerCase()`.
- Fetch API et programmation asynchrone (`async` / `await`).
- Gestion des erreurs avec `try` / `catch`.
